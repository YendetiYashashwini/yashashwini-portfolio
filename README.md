## 🧭 About the Project
A high-performance, recruiter-focused personal portfolio engineered with modern frontend technologies and clean aesthetics. Designed specifically for AI/ML engineering roles, showcasing production deployments, competitive hackathon milestones, and deep technical competencies.

---

## 🛠️ Core Tech Stack

* **Frontend:** React, Vite, Tailwind CSS, Framer Motion
* **Deployment & Hosting:** Vercel (CI/CD Pipeline)
* **AI & Machine Learning:** Python, Scikit-learn, Hugging Face, LLM APIs, LangChain / Agentic Workflows
* **Tools & Version Control:** Git, GitHub, VS Code, Docker, FastAPI, Streamlit

## ⚙️ Local Development Setup

Clone the repository and run the project locally on your machine:

```bash
# Clone the repository
git clone [https://github.com/YendetiYashashwini/yashashwini-portfolio.git](https://github.com/YendetiYashashwini/yashashwini-portfolio.git)

# Navigate to project directory
cd yashashwini-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
